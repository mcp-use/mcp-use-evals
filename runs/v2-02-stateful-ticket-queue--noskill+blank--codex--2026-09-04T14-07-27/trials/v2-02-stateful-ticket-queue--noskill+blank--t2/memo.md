The agent relied primarily on installed-package discovery rather than external docs: it opened `node_modules/mcp-use/README.md`, inspected `node_modules/mcp-use/dist/index.d.ts`, and grepped declarations with `rg -n "listen\\(" node_modules/mcp-use/dist/server.d.ts node_modules/mcp-use/dist/*.d.ts`. This successfully exposed the useful port precedence contract: `Port precedence is the argument, PORT, config.port, then 3000`.

Two avoidable source-edit issues cost iterations. The first generated an invalid escaped description, `describe("Ticket id, for example \\\\"1\\\\"")`, producing `TS1005: ',' expected` and `TS1127: Invalid character`. The second left duplicate and conflicting package module declarations—`"type": "module"` followed later by `"type": "commonjs"`—which caused `TS1309: The current file is a CommonJS module and cannot use 'await' at the top level.`

Protocol verification also took a wrong turn. The initial handshake mixed `MCP-Protocol-Version: 2026-07-28` with an initialize body and received the SDK’s fairly informative error: `the request headers and body disagree: an initialize request (legacy handshake) was sent with a modern MCP-Protocol-Version header`. Retrying without that header and with `"protocolVersion":"2025-06-18"` worked.

The first lifecycle script mishandled SSE framing because it searched using `body.split("\\n")`, leading to `TypeError: Cannot read properties of undefined (reading 'slice')`. That failed script had nevertheless already mutated server state; the diagnostic call then returned `Ticket 2 created.`, so the agent had to restart the server before clean lifecycle verification. The replacement parser used `body.match(/data: (.+)/)` and the later server log confirmed all calls, including repeated claim and unknown-ID paths: `tools/call claim_ticket` three times and `tools/call close_ticket` twice.

A final verification command unnecessarily assumed Git metadata: `git status --short && git diff --check`, ending with `fatal: not a git repository`, although the preceding `npx tsc --noEmit` had completed successfully.
