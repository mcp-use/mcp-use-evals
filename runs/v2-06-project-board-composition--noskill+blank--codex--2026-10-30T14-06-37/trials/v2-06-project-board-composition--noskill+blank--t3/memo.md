The SDK unexpectedly wrote a telemetry identity file during execution: the file listing showed `./.mcp-use/usage.json`. The final source works around this by setting `process.env.MCP_USE_ANONYMIZED_TELEMETRY ??= "false"` before dynamically loading the SDK with `await import("mcp-use")` (`src/server.ts`). This is a notable SDK papercut for a task explicitly requiring no files for state.
