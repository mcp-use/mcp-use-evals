The decisive miss was the explicit decline/cancellation branch in `src/server.ts`: `if (response.kind !== "elicit" || response.action !== "accept")` returns `"Deployment approval was not granted."`, while only accepted content with `approve: false` returns `"Deployment was declined."`. The agent’s own declined HTTP check showed `"text\":\"Deployment approval was not granted.\""`, but it concluded that the exchange “succeeded” without checking that the terminal message identified the decline; this directly aligns with the reported contract failure.

API discovery relied heavily on grepping installed packages rather than a skill file or fetched docs, starting with `rg -n "inputRequired|inputResponse|acceptedContent|streamable" node_modules/mcp-use` and then inspecting `node_modules/@modelcontextprotocol/server` declarations. This did uncover useful guidance such as ``Responses are not validated against it — pass the same schema to `acceptedContent()` ``, but required several searches, including one that returned no output and another with `exitCode:2`.

Manual protocol verification consumed multiple failed attempts because the modern wire requirements were not initially known. The first request failed with `"an initialize request (legacy handshake) was sent with a modern MCP-Protocol-Version header"`, discovery then failed because `"the required Mcp-Method header is absent"`, and the first tool call failed because `"the required Mcp-Name header is absent"`. The agent subsequently reverse-engineered envelope keys via package internals and printed `PROTOCOL_VERSION_META_KEY`, `CLIENT_INFO_META_KEY`, and `CLIENT_CAPABILITIES_META_KEY`.

There were smaller setup papercuts: the first typecheck failed with `Cannot find name 'process'` despite installing `@types/node`, requiring a `tsconfig.json` edit, and the final validation chain failed because `"Not a git repository"` after invoking `git diff --check`. The installation also repeatedly reported `11 high severity vulnerabilities` and an `esbuild` `allowScripts` warning, adding noise to an otherwise successful build and launch.
