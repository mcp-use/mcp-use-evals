The agent never reconciled that layout mismatch because all local commands auto-discovered the root file.

Discovery relied heavily on installed package internals rather than a skill or fetched docs: it inspected `node_modules/mcp-use/README.md`, `node_modules/mcp-use/dist/tools.d.ts`, `node_modules/mcp-use/dist/views/types.d.ts`, and `node_modules/mcp-use/dist/react/hooks/use-tool-context.d.ts`.
