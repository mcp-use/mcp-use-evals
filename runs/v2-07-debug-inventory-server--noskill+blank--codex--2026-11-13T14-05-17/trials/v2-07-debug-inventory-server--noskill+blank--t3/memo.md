It then leaned on grepping installed SDK internals for API shape via `rg -n "class MCPServer|listen\\(" node_modules/mcp-use`, but the result was a large minified `node_modules/mcp-use/dist/index.js` excerpt rather than useful declarations, and no docs URL or skill file was used.
