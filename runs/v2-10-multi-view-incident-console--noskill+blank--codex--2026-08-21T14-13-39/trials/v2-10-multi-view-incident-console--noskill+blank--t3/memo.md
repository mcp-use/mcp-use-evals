The decisive wrong turn was entry placement: the agent created root `index.ts` (`[tool] fileChange({"event":"create","path":"index.ts"})`) after the scaffold advertised `index.ts (server entry point)`, while the grader only searched `src/server.ts` and `src/index.ts`. This is a scaffold/grader convention mismatch: the SDK itself successfully accepted the root entry—`[mcp-use] built index.ts + views ... → .mcp-use/build/index.js`—but the submitted layout was not discoverable by the evaluation workflow.

Discovery consumed substantial effort. The agent fetched the npm README (`npm view mcp-use@2.0.4 readme`), inspected installed declarations (`sed -n '1,180p' node_modules/mcp-use/dist/tools.d.ts`), grepped the CLI bundle for entry behavior (`rg -n "entry|index.ts|server.ts" node_modules/mcp-use/dist/bin.js`), and generated both default and MCP Apps templates (`create-mcp-use-app@2.0.4 ...` and `--template mcp-apps`). The first scaffold attempt also failed because absolute paths were rejected: `Project name cannot contain path separators or ".."`.

The initial runtime failure came from fighting `npm init` output. `package.json` contained both `"type": "module"` and a later `"type": "commonjs"`, so start failed with `Cannot use import statement outside a module`; the agent inspected the file, found `node -p "require('./package.json').type"` returned `commonjs`, and then repaired it.

Verification had another CLI papercut: `mcp-use client` said `[mcp-use] installing @mcp-use/client…` and reported `added 1 package`, but immediately failed with `@mcp-use/client is not installed`, requiring an explicit `npm install -D @mcp-use/client`. That helper resolved to `@mcp-use/client@2.1.5` while the server dependency was confirmed as `mcp-use@2.0.4`, visible in `server/discover mcp-use/2.1.5` and `npm ls ... mcp-use@2.0.4`.

The agent’s own checks otherwise appeared successful—`tools/call list_incidents`, `tools/call get_incident`, and both `resources/read ui://views/...` returned HTTP 200—but those checks did not catch the evaluator’s required source-entry location.
