A package-exports papercut blocked direct dependency inspection: `require('mcp-use/package.json')` failed with `ERR_PACKAGE_PATH_NOT_EXPORTED`. The resulting source carries an explicit workaround at `src/server.ts`: `const issueId = Array.isArray(id) ? id[0] ?? "" : id;`.

A generic repository check wasted a command because the blank workspace was not a Git repository: `warning: Not a git repository. Use --no-index to compare two paths outside a working tree`. Likewise, one verification command reported no response body even though the server log later showed success: the command output was `""`, while shutdown output recorded `tools/call resolve_issue /mcp 200`.

The SDK unexpectedly created local telemetry state during execution: `find` showed `./.mcp-use/usage.json`. The agent then grepped bundled SDK code and found the opt-out check, `env("MCP_USE_ANONYMIZED_TELEMETRY")==="false"`, deleted the generated file, and added `process.env.MCP_USE_ANONYMIZED_TELEMETRY ??= "false";` in `src/server.ts`. This cleanup required extra source inspection (`rg -n "usage\\.json|usage" node_modules/mcp-use/dist`) and a second complete live lifecycle run.
