The decisive wrong turn was placing the entry at repository root as `index.ts` rather than at a grader-recognized location; the produced source is `index.ts`, while the generated declaration also points to `typeof import("./index.js")` in `mcp-env.d.ts`. This was reinforced by the local SDK workflow accepting that layout: build reported ``[mcp-use] built index.ts + views (incident-detail, incident-list) → .mcp-use/build/index.js``, so the agent had no local signal that `src/server.ts` or `src/index.ts` was required.

The agent leaned heavily on package inspection rather than a skill file: it fetched ``npm view mcp-use@2.0.4 readme --json`` and then searched installed SDK internals with ``rg -n "view:|MCPServer|resources|resource" node_modules/mcp-use`` plus direct inspection of ``node_modules/mcp-use/dist/tools.d.ts`` and ``server.d.ts``. That research did lead to the intended one-to-one bindings in `index.ts`, including `name: "incident-list"` and `name: "incident-detail"`.

Verification lost time on a protocol-version mismatch. The first initialize request proposed ``"protocolVersion":"2026-07-28"``, but the server negotiated ``"protocolVersion":"2025-11-25"``; subsequent requests nevertheless sent ``mcp-protocol-version: 2026-07-28`` and failed with ``the request is missing the required per-request envelope key(s): _meta``. The agent recovered by retrying with ``mcp-protocol-version: 2025-11-25``, after which the server log showed successful ``tools/list``, ``resources/list``, both tool calls, and both resource reads.

The resource MIME verification was weakly surfaced: the command searched for ``"mimeType":"text/html;profile=mcp-app"|incident-list|incident-detail``, but its recorded output only contains ``mcp-use server running at http://localhost:3101/mcp``. Despite that, the agent stated, ``both generated resources report the required MCP App HTML MIME type``. Start smoke tests also appeared as tool failures solely because they intentionally used timeouts: ``exitCode":124`` alongside ``mcp-use server running at http://localhost:3000/mcp``.
