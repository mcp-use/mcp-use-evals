The decisive wrong turn was placing the entry at repository root as `index.ts`, while the deterministic grader only tried `src/server.ts, src/index.ts`; the produced source confirms `index.ts` exists and no `src/` entry was created. Local validation therefore passed with `[mcp-use] built index.ts + views`, masking the grader’s narrower entry convention.

The agent leaned heavily on installed-package discovery rather than a skill file or fetched docs: it searched `node_modules/mcp-use/README.md`, inspected `node_modules/mcp-use/dist/server.d.ts`, and grepped the bundled CLI until it found `var i=["src/index.ts",...,"index.ts",...]`.
